# Cost Analysis — AI E-commerce Cart Recovery

## Objective

Estimate the initial implementation and ongoing operating cost of an AI-powered customer recovery workflow for an e-commerce company.

## Upfront implementation estimate

| Component | Estimated cost |
|---|---:|
| Business analysis & use-case design | €800 |
| AI workflow / n8n implementation | €1,500 |
| Prompt design & testing | €700 |
| Dashboard / monitoring setup | €800 |
| Testing & documentation | €700 |
| **Estimated total** | **€4,500** |

## Estimated monthly operating cost

| Component | Estimated monthly cost |
|---|---:|
| Automation infrastructure | €50–150 |
| LLM API usage | €20–100 |
| Monitoring | €0–100 |
| Email / messaging services | €20–50 |
| **Estimated monthly range** | **€90–400** |

## Assumptions

These figures are preliminary consulting estimates for a small/medium e-commerce company.

Actual costs will depend on:

- monthly customer/session volume
- selected LLM model
- number of AI assessments
- automation infrastructure
- monitoring requirements
- email or messaging provider
- integrations with e-commerce and CRM platforms

Token usage and latency are monitored during the POC to support future cost optimization.

## Recommendation

Start with a limited POC before committing to production deployment. The POC should validate:

1. AI recommendation quality
2. hallucination/groundedness
3. customer-message safety
4. latency
5. token consumption
6. business impact

A production investment should only be made after these metrics have been validated with real company data.
