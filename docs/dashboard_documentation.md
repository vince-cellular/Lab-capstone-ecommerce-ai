# Dashboard Documentation — E-Commerce Conversion Performance

## Purpose

This dashboard provides a stakeholder-focused analysis of e-commerce customer behavior using the Online Shoppers Intention dataset.

The objective is to help a business decision-maker understand website traffic, visitor engagement, and conversion performance, and identify potential areas for optimization.

## Stakeholder Metrics

| Metric                   |  Value | Purpose                                                                |
| ------------------------ | -----: | ---------------------------------------------------------------------- |
| Total Sessions           | 12,205 | Measures overall website traffic volume.                               |
| Converted Sessions       |  1,908 | Measures the number of sessions resulting in a purchase.               |
| Conversion Rate          | 15.63% | Measures the overall proportion of sessions that convert.              |
| Average Session Duration |  81.65 | Indicates the average time visitors spend during a session.            |
| Bounce Rate              |  2.04% | Indicates the proportion of sessions with limited further interaction. |
| Product Engagement       |  32.05 | Average number of product-related pages viewed per session.            |

## Visualizations

### 1. Conversion Trend

The monthly conversion trend shows how conversion performance changes between February and December.

The analysis shows a general increase from February toward November, with November representing the highest conversion performance, followed by a decline in December.

### 2. Conversion by Visitor Type

The analysis compares conversion performance between visitor types.

* New visitors: 24.93%
* Other visitors: 19.75%
* Returning visitors: 14.09%

New visitors show the highest conversion rate, while returning visitors show the lowest.

### 3. Conversion by Traffic Type

Conversion performance varies considerably between traffic-source categories.

* Traffic Type 16: 33%
* Traffic Type 13: 5%

The dataset represents traffic sources using numerical categories. The exact business meaning of each category should therefore be validated against the company's traffic-source tracking documentation before making channel-specific investment decisions.

## Key Business Insights

1. Overall conversion is 15.63%, meaning that a significant proportion of sessions do not result in a purchase.
2. Conversion performance generally improves from February to November before declining in December, suggesting a potential seasonal pattern that requires further investigation.
3. Traffic Type 16 has a substantially higher conversion rate than Traffic Type 13, indicating differences in traffic quality or visitor purchase intent.
4. New visitors convert at a higher rate than returning visitors, highlighting returning visitors as a potential area for further investigation.

## Limitations

The analysis is based on a public dataset and therefore does not represent the actual performance of a specific company.

Traffic Type is represented by numerical codes, so the exact acquisition channel behind each code cannot be assumed without additional documentation.

The analysis identifies correlations and patterns but does not establish causal relationships.

## Recommended Next Steps

The business should:

1. Investigate the characteristics of the highest-performing traffic sources.
2. Analyze why returning visitors have a lower conversion rate than new visitors.
3. Investigate the seasonal increase in conversion toward November.
4. Segment conversion performance further by device, traffic source, and visitor type before making marketing investment decisions.
