# Timeline Estimate — AI E-commerce Cart Recovery

## Phase 1 — POC

**Duration: 1–2 weeks**

- Confirm business requirements
- Configure n8n workflow
- Connect AI model
- Develop recovery prompt
- Create test dataset
- Configure monitoring
- Test AI outputs

## Phase 2 — Pilot

**Duration: 3–4 weeks**

- Connect to real e-commerce data
- Integrate customer communication channel
- Test with a limited customer segment
- Monitor quality, latency and cost
- Measure conversion/recovery impact
- Refine prompts and business rules

## Phase 3 — Production deployment

**Total estimated timeline: 6–8 weeks**

- Production infrastructure
- Security and data protection review
- GDPR assessment
- Integration with e-commerce/CRM systems
- Monitoring and alerting
- User acceptance testing
- Production launch

## Key assumptions

The timeline assumes:

- access to required e-commerce data
- availability of a technical contact
- no major legacy-system integration issues
- limited initial scope
- approval of AI and data-protection requirements

The timeline is indicative and should be refined after technical discovery.
